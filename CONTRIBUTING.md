# Участие в разработке

Нужны Linux, Python 3.11+, Git и Node.js >=20.19.0. Склонируйте репозиторий в
удобный каталог; абсолютный путь не является частью публичного контракта.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
npm --prefix tools/openspec ci --ignore-scripts --no-audit --no-fund
./bin/test-changerail -k '<имя_затронутой_регрессии>'
.venv/bin/python -m ruff check scripts tools/changerail/tests distribution.py
git diff --check
```

Установка npm — явное provision-действие. Во время доставки нет сетевого
fallback. При наличии кэша используйте `tools/openspec/bootstrap.sh --offline`.

Воспроизведите ошибку регрессией, исправьте общий исходник и выполните затронутые
проверки. Тесты доказывают поведение через файлы, Git, subprocess и evidence;
ответы модели в тестах подставляются явно. Полный повтор в каждом потребителе
не нужен. Проектные данные и журналы реального испытания оставляйте локально.

Полный набор принадлежит CI ChangeRail: Python 3.11/3.12, Node wrapper, Ruff,
скан публичной поверхности и diff. `./bin/test-changerail` без фильтра запускает
полный Python-набор; используйте его осознанно, не при каждой установке runtime.
Остановленный оператором набор не перезапускайте автоматически.
Test extras включают `uv`: часть subprocess-регрессий реально вызывает
`uv run pytest` и `uv run ruff`. Обеспечьте доступ к инструментам `.venv/bin`
в окружении проверок, включая login shell `bash -lc`, который использует runner.
Сам выбор `.venv/bin/python` не меняет PATH дочерних команд.

Для правок документации сверяйте CLI с текущим parser, проверяйте ссылки
и примеры на временном generic проекте. Не запускайте модельную доставку
ради проверки инструкций установки. Правка agent skill меняет frozen identity,
поэтому совместимость остановленных запусков требуется объяснить даже в
документационном релизе. Процедура выпуска — в [runbook](docs/releasing.md).

Обобщённую регрессию добавляйте сюда без данных потребителя. PR описывает
проблему, поведение, проверки и совместимость сохранённых запусков. Изменения
review, repair, publication или доверия к ссылкам требуют сценариев отказа.
