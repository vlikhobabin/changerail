# Участие в разработке

Нужны Linux, Python 3.11+, Git и Node.js >=20.19.0. Склонируйте репозиторий в
удобный каталог; абсолютный путь не является частью публичного контракта.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
npm --prefix tools/openspec ci --ignore-scripts --no-audit --no-fund
./bin/test-changerail
```

Установка npm — явное provision-действие. Во время доставки нет сетевого
fallback. При наличии кэша используйте `tools/openspec/bootstrap.sh --offline`.

Воспроизведите ошибку регрессией, исправьте общий исходник и выполните затронутые
проверки. Тесты доказывают поведение через файлы, Git, subprocess и evidence;
ответы модели в тестах подставляются явно. Полный повтор в каждом потребителе
не нужен. Проектные данные и журналы реального испытания оставляйте локально.

Обобщённую регрессию добавляйте сюда без данных потребителя. PR описывает
проблему, поведение, проверки и совместимость сохранённых запусков. Изменения
review, repair, publication или доверия к ссылкам требуют сценариев отказа.
