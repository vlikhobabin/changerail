# ChangeRail 1.0.0

Дата выпуска: 2026-09-01.

Canonical publication identity: annotated tag `v1.0.0` с exact message
`ChangeRail 1.0.0`, GitHub Release title `ChangeRail 1.0.0`; exact release
notes body — полный UTF-8 текст этого tracked файла.

`1.0.0` — первый stable release ChangeRail: public workflow/toolchain для
OpenSpec artifacts, board-driven delivery, reusable agent skills, independent
review gates, scoped publish, project bootstrap и verification.

## Highlights

- Stable `explore → ff → do → review → pub` lifecycle с supervised
  `$changerail-deliver` orchestration.
- Fail-closed manifest scope, review freshness, risk/complexity preflight,
  execution-target и verification-coverage contracts.
- Recovery-aware runner status/evidence/metrics и bounded resume policies.
- Split Linux-focused core/extended release suites и bounded public
  reachable-history verification.
- Reproducible language-neutral source archive с exact version, license,
  source revision и SHA-256 metadata.

Полный список изменений и breaking markers находится в
[`CHANGELOG.md`](../../CHANGELOG.md). Переход с `0.5.0`, required actions и
rollback описаны в [`docs/migration-guide.md`](../migration-guide.md), support
boundary — в [`docs/compatibility.md`](../compatibility.md).

## Distribution

Release публикует maintainer-owned assets:

```text
changerail-1.0.0.tar.gz
changerail-1.0.0.tar.gz.sha256
changerail-1.0.0.release-metadata.txt
```

Проверка archive:

```bash
sha256sum --check changerail-1.0.0.tar.gz.sha256
tar -xzf changerail-1.0.0.tar.gz
test "$(cat changerail-1.0.0/VERSION)" = "1.0.0"
```

Metadata sidecar должен называть exact dereferenced `v1.0.0` commit, archive,
checksum и `LICENSE`. Canonical license — MIT в root [`LICENSE`](../../LICENSE).

## Support Boundary

Stable admission для `1.0.0` является Linux-focused. Native Windows wrappers,
generated-copy wiring и lab diagnostics остаются доступными, но native Windows
не release-certified для этой версии: fresh public-safe live proof exact
candidate не заявляется и synthetic host evidence не используется.

## Upgrade And Rollback

После проверки checksum следуйте migration guide и перезапустите активные
Codex/Claude sessions. Rollback возвращает ChangeRail checkout и consumer lock
к reviewed `v0.5.0` state и повторяет project verification. Immutable
`v1.0.0` tag не перемещается; corrections публикуются новым semver.
