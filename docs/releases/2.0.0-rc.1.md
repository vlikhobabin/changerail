# ChangeRail 2.0.0-rc.1

Предварительный выпуск общего native runtime опубликован 10 сентября 2026 года:
[GitHub Release v2.0.0-rc.1](https://github.com/vlikhobabin/changerail/releases/tag/v2.0.0-rc.1).
Версия Python metadata — `2.0.0rc1`, коммит выпуска —
`eba400075417f62308b570cd6be2b0c1a0aa575e`.

## Изменения

- Единственный исполнительный lifecycle — `openspec-v1`: одна карточка, один
  native change и максимум два независимых ревью с общим остатком для repair.
- Общий исходник, runtime-копии и проектные профили имеют отдельное владение.
  Подключение через ссылки сохраняет изоляцию Git, board и evidence потребителей.
- Evidence связывается с фактическими байтами, командой, ролью и текущим payload.
  Повтор неизменённой неудачной или прерванной проверки блокируется.
- Runtime-архив собирается детерминированно, проверяется по манифесту и хешам,
  устанавливается с delivery lock, backup и откатом перехваченных ошибок.
- Исправлены неполная frozen identity OpenSpec, отсутствие ignore-проверки
  при attach и восстановление detach после утраты общего checkout.
- Прерванный до перемещения archive продолжает работу в следующие UTC-сутки
  через цепочку квитанций, сохраняя исходный intent и accounting.
- Node выбирается из PATH; CI проверяет Python 3.11/3.12, OpenSpec wrapper,
  Ruff и публичную поверхность.

## Совместимость и ограничения

Linux — текущая платформа. Нужны Python 3.11+ и Node.js >=20.19.0; закреплён
OpenSpec 1.3.1. Прежние FF, board-only, offline и Windows исполнительные маршруты
удалены. Их артефакты доступны в Git-истории, включая тег `v1.0.0`.

Установка нового кода не разрешает продолжать старые frozen runs. Runtime repair
ограничен остановленным первым native run с shared-source до принятых checkpoints
и evidence. Старые записи с неполной process identity автоматически не дополняются.
Профили, настройки агентов, credentials и runtime-журналы не входят в выпуск.

Смена UTC-даты внутри уже работающего stock archive всё ещё вызывает остановку.
Сквозной сценарий всех gates с подставленной моделью и дальнейшее разделение
`local_delivery.py` остаются следующими задачами. Предварительный выпуск не
утверждает доказанную реальную модельную доставку у конкретного потребителя.

## Проверки и выпуск

[CI точного коммита](https://github.com/vlikhobabin/changerail/actions/runs/34440903391)
успешно завершён на Python 3.11 и 3.12: в каждой конфигурации прошли 802
Python-теста, 8 проверок OpenSpec wrapper, Ruff, скан публичной поверхности и
проверка diff. При подготовке также выполнена строгая валидация спецификации.

Публикуемый runtime-архив: `changerail-2.0.0-rc.1-runtime.tar.gz`.
К нему прилагаются `SHA256SUMS` и `release-provenance.json` с точным source commit,
source tree и hash архива. Поле `upstream_commit` внутри дистрибутива обозначает
историческое происхождение ядра, а не самоссылку на release commit.

Перед созданием тега проверены будущая Git-выборка, достижимая история,
воспроизводимость архива и совпадение его файлов с release commit. Исходники
тестов остаются в Git; runtime-архив исключает тесты, зависимости, локальные
профили и журналы. Миграция описана в [документации](../migration.md), подключение —
в [shared-source](../shared-source.md), установка — в [DISTRIBUTION.md](../../DISTRIBUTION.md).
