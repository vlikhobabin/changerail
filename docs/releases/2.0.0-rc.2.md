# ChangeRail 2.0.0-rc.2

Предварительный выпуск с актуализацией документации и инструкций reviewer.
Тег — `v2.0.0-rc.2`, версия Python metadata — `2.0.0rc2`.
[Страница выпуска](https://github.com/vlikhobabin/changerail/releases/tag/v2.0.0-rc.2)
содержит точную дату публикации, commit, результаты CI и файлы дистрибутива.

## Изменения

- Добавлен путь первой установки из опубликованного архива: проверка хешей
  и provenance, настройка проекта, принятие карточки и запуск доставки.
- Добавлено руководство оператора: диагностика, остановка, resume, ошибки
  frozen identity, прерванная проверка и незавершённая публикация/установка.
- Исправлен выбор потребителя в командах shared-source repair. Ограничение
  detach описано точно: любой новый или изменённый run блокирует отключение.
- Описаны реальные полномочия Codex launcher, исполнение shell-команд и
  обязательный commit/push при успешной доставке.
- Добавлен runbook выпуска с проверкой точного Git commit, публичной выборки,
  истории, воспроизводимости архива и скачанных release assets.
- OpenSpec README переведён на русский; инструкции bootstrap и `--project`
  уточнены. Обновлены навигация, шаблонные пути, описание runtime и сведения
  о публикации rc.1.
- Review skill больше не предполагает обязательное наличие board README
  в потребителе; источником дополнительных правил служит контекст проекта.

## Совместимость

Python-код runtime, схемы и lifecycle не менялись: Linux, Python 3.11+,
Node.js >=20.19.0, pinned OpenSpec 1.3.1, одна карточка / один native change,
максимум два независимых ревью с общим остатком для repair.

Изменение review skill входит в frozen execution identity. Установку или
обновление shared checkout выполняют после остановки затронутых доставок;
старые runs не получают права resume по новому skill. Python runtime repair
не разрешает такую замену. Проверяйте точный inventory и сохраняйте историю
по документированной процедуре обновления.

Автоматическое reconciliation для detach после новых runs и автоматическое
восстановление после SIGKILL/потери питания не добавлены. Runbooks описывают
эти ограничения. Сквозное доказательство реальной модельной доставки у
конкретного потребителя остаётся его отдельной проверкой.

## Проверки и файлы

Публикация требует успешного полного CI точного коммита на Python 3.11/3.12,
проверок wrapper, Ruff, публичной поверхности и diff. Ссылка на завершённый CI
добавляется на страницу выпуска после получения результата.

Архив — `changerail-2.0.0-rc.2-runtime.tar.gz`; дополнения — `SHA256SUMS` и
`release-provenance.json`. Provenance содержит фактические source commit/tree
и хеш архива. Исторический `upstream_commit` внутри комплекта сохраняется.
Расширенные runbooks остаются в Git; README runtime ссылается на точный тег.
