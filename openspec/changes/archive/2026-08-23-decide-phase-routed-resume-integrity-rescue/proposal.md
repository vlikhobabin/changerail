## Why

Fresh independent review cycle 3 отклонил phase-routed replacement: retained
terminal command допускает conflicting push authority, repair counter не
выводится из истории, второй последовательный resume теряет фактического
aggregate-owner receipts, а разные aliases одного Git worktree проходят plan
admission. Same-card rescue budget исчерпан `2/2`, поэтому текущий 488-line
production candidate может быть только входом нового decision-only
investigation, а не третьим repair или publishable payload.

## What Changes

- Публикуется одно fail-closed решение для exact parsed child argv/effective
  `no-push`, производного repair count, полной recursive `resume_from` lineage
  и уникальности canonical Git workspace roots.
- Cycle-3 R1-R4 связываются с production boundaries, а R5 превращается в
  connected regression matrix с доказанным canonical base, точной причиной
  каждого отказа и `model_launch_delta: 0` для negative probes.
- Выбирается одна atomic replacement-карточка
  `replace-phase-routed-resume-integrity-boundary` с ceiling 500 added
  production LOC; rejected 488-line candidate должен быть перестроен через
  замену и консолидацию проверок, а превышение ceiling является hard stop.
- Фиксируются exact successor и отдельный authorization source с полным
  шестиполевым object; старая authorization не переиспользуется.
- Подтверждается отсутствие необходимости в дополнительном versioned wire
  field: unpublished v1 candidate fields уже достаточны, а residual fixes
  принадлежат semantic validation.
- Investigation остается decision-only: во время apply phase допускается ровно
  одна синхронизация его delta requirement в main spec
  `openspec/specs/changerail-delivery-runner/spec.md`, как требует task 2.1.
  Production runner, schemas, tests, CLI, public runtime docs и runtime
  behavior не меняются.

## Capabilities

### New Capabilities

- none

### Modified Capabilities

- `changerail-delivery-runner`: добавить нормативное rescue-решение для exact
  command authority, derived repair state, recursive resume ownership,
  canonical workspace admission, bounded successor и connected regression
  floor.

## Impact

В этом change изменяются только investigation card и OpenSpec artifacts.
Будущий exact successor затронет `bin/changerail-delivery-runner`, существующие
phase-routed v1 schemas, `scripts/smoke-delivery-runner.py`, public contracts и
delta spec; consumer projects получат fail-closed admission без target,
credential или provider substitution. Отдельная будущая authorization-card
будет публичным six-field source для exact successor.
