## Why

Fresh independent review cycle 3 повторил один decoded-target defect class уже
во второй последовательной implementation lineage: pair-preserving parser
использовал array-valued `investigation_id` в set membership до type/duplicate
validation, выбросил `TypeError` и не вернул structured fail-closed preflight.
Обе lineage исчерпали repair budget, поэтому следующий шаг требует
decision-only investigation, а не ещё одного rescue.

## What Changes

- Публикуется total/non-throwing порядок authorization classification:
  pair-preserving decode, linear typed hint extraction, exact candidate
  selection, duplicate/shape/type validation, materialization и только затем
  semantic relations/review eligibility.
- Запрещается hashing или set membership для любого unvalidated decoded
  identity value; pair order и decoded duplicate spellings сохраняются до
  rejection.
- Фиксируется полный connected canonical-base cross-product для четырех
  identity keys, всех JSON scalar/container types, alternate-escaped duplicate
  keys в обоих порядках, shape, candidate-selection и semantic relations с
  exact structured oracle и zero model launch.
- Выбирается один следующий authorization item
  `authorize-type-safe-phase-routed-resume-integrity-payload`, его reciprocal
  relations, exact six-field object, successor ceiling 500 и protocol allowance
  `true`; сам item и downstream successor в этом change не создаются.
- Rejected source/rescue payloads остаются forensic-only без repair или
  publish. Review получает fresh `GO`; только publish/finalization требуют GO.
- Investigation остается decision-only: fast-forward меняет только card и
  OpenSpec artifacts. Production code, schemas, tests, CLI, public runtime docs
  и runtime behavior не меняются.

## Capabilities

### New Capabilities

- none

### Modified Capabilities

- `changerail-contracts`: добавить нормативное решение для total type-safe
  decoded authorization target classification, connected matrix и exact
  replacement authorization source.

## Impact

В planning change изменяются только investigation card и
`openspec/changes/decide-type-safe-decoded-target-classification-boundary/`.
Будущий authorization item затронет
`scripts/changerail_review_preflight.py`, `scripts/smoke-review-preflight.py`,
один exact source card и `changerail-contracts`; его production delta ограничен
300 LOC. Будущий phase-routed successor остается отдельной critical карточкой с
ceiling 500 и protocol allowance `true`; consumer target/provider/credential
authority не меняются.
