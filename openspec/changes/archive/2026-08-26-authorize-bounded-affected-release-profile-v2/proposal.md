# Proposal: bounded affected release profile v2 authorization

## Why
The published exact report/proof decision requires a separately published
docs-only authorization before the clean v2 implementation may be created.

## What Changes
- Bind one exact six-field decision object to one future implementation.
- Freeze exact dependencies, sole block, two-field future reference and LOC cap.
- Preserve every published report/protocol/CI/connected-proof boundary.
- Keep implementation, runtime authority and expensive evidence absent.

## Impact
- Methodology: publication order and successor authority become machine-checkable.
- Verification: future implementation has one exact bounded contract.
- Public surface: docs/OpenSpec only; no code, dependencies or runtime state.
- Consumer projects: no impact.
