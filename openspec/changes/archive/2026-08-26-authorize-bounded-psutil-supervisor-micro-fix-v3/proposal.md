## Why

The published terminal micro-fix decision defines the sole eligible S3
reconstruction, but requires a separately published authorization source before
the exact successor can exist. This change establishes that source without
turning frozen terminal material into authority or evidence.

## What Changes

- Add one docs-only six-field `Investigation authorization` object bound to
  `decide-bounded-unpublished-terminal-micro-fix-boundary` and only
  `deliver-psutil-backed-release-child-supervisor-v3`.
- Preserve reciprocal decision/authorization/future-successor lineage, the
  exact future two-field reference, successor absence and the `<=499` added
  production-LOC limit against this authorization-publishing HEAD.
- Synchronize the exact S3 eligibility, clean reconstruction, evidence
  non-reuse, fresh R1-R7 proof, R7 EOF, one-attempt, `0/0/0` budget and
  dormancy contract.
- Keep the authorization docs-only: production, test and runtime LOC remain
  `0`; no successor, downstream refresh, history, full baseline, live proof,
  review, commit or push is created or accepted as evidence.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `changerail-release-ci`: add the publishable S3 authorization source and its
  exact bounded future micro-fix contract.

## Impact

Only the authorization board card, same-slug OpenSpec artifacts, synchronized
`changerail-release-ci` specification and archive metadata change. Production
code, dependencies, tests, runtime state, release baseline, CI, successor
card/code, review, commit and push remain unchanged.
