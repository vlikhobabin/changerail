## Why

Published v8 investigation закрыл повторяющиеся typed-target,
execution-ownership и connected-proof boundaries, но clean implementation не
может существовать до отдельной reviewed и remotely published authorization.

## What Changes

- Публикуется exact six-field investigation authorization для единственного
  clean `implement-bounded-affected-release-profile-v8` successor.
- Future implementation связывается с exact two-field authorization reference,
  published source/dependencies, `<=499` production LOC и sole certification
  block.
- Сохраняются retained pre-production RED, exhaustive typed registry, closed
  execution ownership, source-connected proof и весь earlier affected floor.
- Authorization остаётся docs-only и не создаёт successor, executable или
  runtime authority.

## Capabilities

### New Capabilities

- none

### Modified Capabilities

- `changerail-release-ci`: добавляет exact bounded authorization и dormancy
  contract для clean affected profile v8 implementation.

## Impact

Только authorization card, same-slug OpenSpec artifacts и main
`changerail-release-ci` specification. Production, tests, workflows, schemas,
dependencies, runtime state, implementation successor и certification не
создаются и не изменяются.
