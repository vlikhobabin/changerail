## Why

Terminal unpublished affected v7 исчерпал единственную same-card repair, но
fresh cycle-2 review повторно обнаружил незакрытые registry-admission,
execution-ownership и connected-proof boundaries. Повтор этих blocker classes
запрещает ещё одну implementation rescue без отдельного investigation/design
решения.

## What Changes

- Фиксируется clean v8 lineage от exact published v7 authorization tip без
  импорта terminal v7 payload или runtime evidence.
- Registry admission становится исчерпывающим typed inventory contract для
  всех operands физических tasks и frozen targets, без path-shape heuristics.
- Python ownership становится closed binding/call/execution inventory, который
  отклоняет aliases, rebinding, wrappers и дополнительные semantic execution
  surfaces.
- Counterfactual proof связывается с source-level mutation фактического
  production guard и public runner/oracle outcome без disconnected mocks.
- Определяется единственный порядок: decision, отдельно опубликованная v8
  authorization, clean v8 implementation, затем certification.

## Capabilities

### New Capabilities

- none

### Modified Capabilities

- `changerail-release-ci`: добавляет normative clean-v8 lineage, typed target,
  closed ownership/execution и connected source-mutant proof boundaries.

## Impact

Change docs-only: board card, same-slug OpenSpec artifacts и main
`changerail-release-ci` specification. Production, tests, workflow, schemas,
dependencies, runtime authority, successors и certification не изменяются и
не создаются.
