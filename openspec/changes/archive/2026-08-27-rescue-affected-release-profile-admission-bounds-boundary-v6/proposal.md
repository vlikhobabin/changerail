## Why

Affected v5 exhausted its sole review repair while a runtime-output existing-file
fault could fail before bounded admission and required selector-bound guards still
lacked connected counterfactuals. Repeating another implementation rescue without
an explicit investigation/design boundary would continue the same proof-defect
class and could not safely unblock certification.

## What Changes

- Publish one docs-only v6 rescue decision from exact safe v5 authorization
  `3588c1d3de0ddc9d8ef50e81992620fc107e4e90`.
- Freeze pre-filesystem aggregate admission and exact runtime-output absent/
  directory/type/symlink/root/access behavior with bounded zero-launch failure.
- Freeze connected non-noop proof for per-path `MAX_PATH`, aggregate
  `MAX_PATHS`, each stream's `MAX_GIT_BYTES` and aggregate four-stream bytes.
- Carry concise two-cycle terminal findings and make unpublished v5 wholly
  forensic-only rather than an implementation source.
- Define one future v6 authorization/implementation lineage while keeping both
  successors absent until this decision is reviewed, published and reachable.
