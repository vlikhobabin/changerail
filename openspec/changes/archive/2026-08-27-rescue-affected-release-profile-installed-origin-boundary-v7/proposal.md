## Why

Terminal affected v6 exhausted its sole same-card repair while one installed-
origin admission blocker remained: production-default `sysconfig` handling
accepted non-package roots. A separate published docs-only decision is required
before any clean successor may narrow that boundary.

## What Changes

- Bind future v7 distribution origins exclusively to exact effective-interpreter
  `purelib`/`platlib` paths and reject every other `sysconfig` root.
- Require connected production-default counterexamples that cannot be hidden by
  an injected allowlist.
- Preserve repaired v6 admission, selector, scheduler, authority, CI, RED and
  protocol non-authority floors.
- Freeze a rescue → authorization v7 → clean implementation v7 → certification
  order while keeping terminal v6 forensic-only.

## Capabilities

### New Capabilities

- none

### Modified Capabilities

- `changerail-release-ci`: Add the exact effective-interpreter package-root and
  connected default-origin proof boundary for a clean affected v7 successor.

## Impact

This change modifies only its board card, same-slug OpenSpec artifacts and the
`changerail-release-ci` specification. It adds no production, test or runtime
behavior, creates no successor card and runs no release/certification surface.
