## Why

Published investigation v13 закрыл exact RED exception-line, independent
Unicode oracle и direct activation proof, но сам не разрешает executable
successor. Перед чистой implementation нужен отдельный remotely published
docs-only authorization source с exact successor identity и bounded LOC ceiling.

## What Changes

- Опубликовать exact six-field investigation authorization только для
  `implement-bounded-affected-release-profile-v13` с ceiling `500` и protocol
  allowance.
- Зафиксировать единственный two-field authorization reference будущей
  implementation, exact dependencies, sole certification block и максимум 499
  added production LOC.
- Перенести без ослабления original pre-mutation RED tree/line contract,
  independently authored Unicode 16.0.0 scalar oracle и normative digest byte
  serialization.
- Перенести lexical depth-one direct connected `run_plan`, v11 runtime-root,
  task pre-reservation, scheduler matrix и accumulated affected-profile floor.
- Сохранить authorization строго docs-only: successor, focused tests,
  production, CI, history/release/live/certification execution отсутствуют.

## Capabilities

### New Capabilities

- none.

### Modified Capabilities

- `changerail-release-ci`: добавить exact docs-only authorization v13 для
  единственного clean bounded affected-profile implementation successor.

## Impact

Изменяются только card, same-slug OpenSpec artifacts, синхронизированный
`openspec/specs/changerail-release-ci/spec.md` и archive metadata. Production,
tests, CI, runtime protocol и publication authority не меняются. Terminal v12
payload/runtime evidence остаются forensic-only.
