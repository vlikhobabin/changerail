dangling-symlink admission, source-bound scheduler-matrix и public rename/copy
proof gaps, но сам не разрешает executable successor. Перед чистой
implementation v14 нужен отдельный remotely published docs-only authorization
source с exact successor identity и bounded LOC ceiling.

  allowance.

  dependencies, sole certification block и максимум `499` added production
  LOC.
- Перенести без ослабления independently frozen descriptor identity,
  non-following runtime-root admission, source/guard-bound scheduler catalog и

- Сохранить authorization строго docs-only: implementation card, focused
  tests, production, CI, history/release/live/certification execution
  отсутствуют.
