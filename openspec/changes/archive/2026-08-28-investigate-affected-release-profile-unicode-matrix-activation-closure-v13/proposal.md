## Why

Terminal unpublished v12 исчерпал единственный same-card rescue и остался с
двумя proof-дефектами: RED receipt не фиксировал непрерывную exact exception
line, а Unicode table мог самосертифицироваться через oracle общего
происхождения. До новой executable попытки нужен чистый опубликованный
docs-only decision, который замкнёт обе границы без чтения terminal payload.

## What Changes

- Зафиксировать exact contiguous missing-module exception line как обязательный
  retained RED output и запретить fragment/substr или позднюю reconstruction.
- Определить нормативно отдельный independently authored Unicode 16.0.0
  `Cc|Cf` oracle, который не generated/copied/derived из production table или
  её digest/helpers и независимо проверяет membership, boundaries, counts и
  digest.
- Сохранить frozen `23 ranges / 235 code points`, stable U+11F00 nonmember и
  depth-one direct `run_plan` activation в lexical body `profile.main` со
  строгим запретом guarded/wrapped/alternate/disconnected calls.
- Сохранить опубликованные v11 runtime-root, scheduler matrix и accumulated
  affected-profile contracts, задать порядок investigation → authorization v13
  → clean implementation v13 → certification.
- Не добавлять executable behavior: production/test/runtime LOC остаются `0`,
  v13 authorization/implementation и certification не создаются.

## Capabilities

### New Capabilities

- none.

### Modified Capabilities

- `changerail-release-ci`: добавить clean v13 investigation boundary для exact
  RED exception-line retention, independently authored Unicode oracle и direct
  activation closure перед отдельной authorization.

## Impact

Изменяются только card, same-slug OpenSpec artifacts, синхронизированный
`openspec/specs/changerail-release-ci/spec.md` и archive metadata. Production,
tests, CI, runtime protocol и publication authority не меняются. Terminal v12
payload/runtime evidence остаются forensic-only.
