## Risks / Trade-offs

- **[Risk] The v18 inventory contains versioned runtime labels.** It is a
  published immutable proof anchor; v19 must match it or require a new tracked
  investigation, never silently rewrite it.
- **[Risk] A disposable hosted layout is treated as live authority.** The
  contract limits it to focused source-safe proof; certification retains sole
  critical execution authority.
- **[Risk] Catalog and observer drift together.** Separate authorship,
  source-derived rows, full bidirectional equality and dynamic projection
  prevent a count-only coordinated pass.
- **[Risk] Implementation exceeds bounded scope.** Preflight checks exact
  authorization/base and rejects more than 499 added production LOC.
