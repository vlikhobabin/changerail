## Risks / Trade-offs

- **[Risk] Phase A indirectly probes through a helper.** Pre-import external
  observers and stage catalog reject every process event before the barrier.
- **[Risk] Canonical npm/npx uses a launcher symlink.** Directory ancestors
  remain symlink-free; only the closed bounded contained final launcher chain
  is allowed and independently resolved.
- **[Risk] CI major does not name a patch.** The oracle requires exactly one
  matching strict filesystem patch rather than hardcoding one.
- **[Risk] Catalog and worklist drift together.** Separate authorship, complete
  field equality, owner/predecessor closure and dynamic exact-row mapping fail
  closed.
- **[Risk] Implementation exceeds bounded scope.** Preflight checks exact
  authorization/base and rejects more than 499 added production LOC.
