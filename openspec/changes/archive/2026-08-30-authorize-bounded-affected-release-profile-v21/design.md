## Risks / Trade-offs

- **[Risk] Nested execution changes physical result cardinality.** One typed
  group executor remains one outer task/result while each immutable argv is
  observed at the published inner broker.
- **[Risk] Scheduler output can be forged.** Exact closed envelope and
  cross-field ownership validation precede pass and authority.
- **[Risk] Interpreter-local hooks miss spawn/exec work.** Pre-import
  `sitecustomize`, bounded nonce transport and mandatory topology registration
  cover each interpreter and fail on incomplete observation.
- **[Risk] Test bootstrap becomes a reachability oracle.** Production must not
  read it, and its events are excluded from row/pass/authority evidence.
- **[Risk] Implementation exceeds bounded scope.** Preflight checks exact
  authorization/base and rejects more than 499 added production LOC.
