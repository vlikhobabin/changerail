## Why

Terminal unpublished affected-profile implementation v19 исчерпала единственный
same-card repair и завершила fresh `NO-GO` с тремя blockers: process probes
происходили до runtime/task-root admission, hosted toolcache принимал symlinked
ancestor и не имел независимо выведенного из CI oracle, а полный activation row
set оставался отсоединён от отдельной worklist/projection. Новый executable
patch запрещён до clean published design closure этих трёх инвариантов.

## What Changes

- Зафиксировать двухфазный aggregate admission barrier, который завершает все
  repository/registry/origin/package/runtime/task-root проверки до первого
  process или Git event и доказывается внешним pre-import observer.
- Зафиксировать component-safe hosted setup-node oracle: CI independently
  задаёт major/layout, filesystem observation выбирает единственный patch/arch,
  каждый directory ancestor проверяется без symlink traversal, а npm/npx
  launcher resolution остаётся bounded внутри canonical version subtree.
- Заменить раздельные activation rows и literal edge worklist одной
  source-derived context-sensitive worklist, которая непосредственно назначает
  row reachability/predecessors и является единственным источником static
  projection для bidirectional catalog и dynamic-trace equality.
- Заморозить clean порядок v20: эта investigation, отдельная docs-only
  authorization, чистая implementation с новым original RED, затем final
  certification.
- Сохранить immutable published v18 proof inventory, accumulated affected floor
  и full-release-only publication authority без executable mutation.

## Capabilities

### New Capabilities

- none.

### Modified Capabilities

- `changerail-release-ci`: добавить normative v20 design closure для pre-process
  aggregate admission, component-safe CI-derived hosted targets, unified
  activation worklist/projection и единственного bounded successor lineage.

## Impact

Change затрагивает только board/OpenSpec documentation, synchronized
`openspec/specs/changerail-release-ci/spec.md` и archive metadata. Production,
tests, runtime behavior, CI execution и authority protocol не изменяются;
terminal v19 payload/evidence остаются forensic-only.
