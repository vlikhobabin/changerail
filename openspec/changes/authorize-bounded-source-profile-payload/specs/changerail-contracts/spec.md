## ADDED Requirements

### Requirement: Source-profile authorization MUST bind exact successor
ChangeRail MUST принимать source-profile protocol authorization только для exact
`materialize-versioned-source-classification-profiles` successor in
`3.inprogress`, bound к published batch investigation, ceiling 500 и protocol
allowance true.

#### Scenario: Exact source-profile chain
- **WHEN** reciprocal links совпадают и existing effective rules source сохранен
- **THEN** preflight применяет bounded exception

#### Scenario: Hidden effective rules source added
- **WHEN** payload или другой successor добавляет implicit rules authority
- **THEN** authorization неприменима
